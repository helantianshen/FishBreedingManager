# 任务状态与 HANDOFF
HANDOFF 描述一个具体任务的当前状态，不是项目总日志，也不是所有需求共用的流水账。优先使用 .agent/tasks/<task-id>.md；项目级 .agent/PROJECT.md 只记录稳定事实和长期约束。
开始任务时只读取明确匹配的任务文件。没有匹配文件时，小型一次性任务可直接执行；可能跨 Session、需要多阶段验证或需要交接的任务创建新文件，不复用旧文件。
在主要阶段完成、关键决策确定、验证发现重要问题、任务阻塞、风险或剩余工作变化、Session 可能结束或需要交接时更新。不要在每次读取、编辑、命令或工具调用后更新。
任务文件按需记录目标范围、当前状态、完成项、决策和理由、重要文件、验证及结果、问题风险和假设、剩余工作、下一步、更新时间；区分事实、推断、未验证假设和用户决定。
完成有实际修改的长任务前同步对应任务文件。本项目不保留历史任务归档；任务结束后将仍有效的事实整合到现行项目文档，删除临时任务文件。纯只读分析和当前会话即可完成的小修改不强制创建 HANDOFF。
