# 运行环境与基础设施规则
不要把本文件、历史会话或其他机器的环境描述当作当前事实。开始构建、测试、安装或排查前，确认操作系统和架构、Shell、项目路径及边界、本机或容器或远程环境、可用运行时和工具、项目版本要求，以及网络、凭据和权限限制；命令必须匹配当前 Shell。
遇到数据库、容器、缓存、消息队列或其他基础设施时，先确认项目配置和已有服务的位置、端口、状态与连接方式。不要因当前环境找不到命令或服务就推断整台机器没有它。未经明确要求，不安装第二套已有基础设施、不创建平行环境、不修改系统级配置、不删除运行时、不改变全局 PATH、默认版本或启动配置。
连接失败时区分未安装、未启动、不可访问、凭据错误、配置不匹配和权限不足。优先低风险只读检查。
优先使用项目声明且已验证可用的版本。发现版本错误时记录实际版本、读取约束、检查已有版本，并优先使用当前会话或进程范围的临时切换；不要未经授权修改默认版本、启动脚本或全局配置。
安装软件、启动服务、改配置、改 PATH、修改代理、调整权限和删除版本都可能产生持续影响。先说明原因、影响范围和回退方式。报告中分开写环境事实、推断和建议，准确记录检查结果。
